Open-Source Implementations

qurac-kyber

Constant-time C implementation of CRYSTALS-Kyber (ML-KEM) with ARM Cortex-M4 assembly optimizations and side-channel test harness.

C / ASM
GitHub →

qurac-dilithium-fpga

RTL implementation of CRYSTALS-Dilithium (ML-DSA) in VHDL/Verilog, including masked arithmetic core and NIST KAT test infrastructure.

VHDL/Verilog
GitHub →

pq-pki-toolkit

Python toolset for assessing PKI readiness and generating hybrid X.509 certificates with CRYSTALS-Dilithium + ECDSA dual signatures.

Python
GitHub →

tamarin-pqc-extensions

Tamarin
